## 项目说明

ablock 是一个**容器安全学习项目**，目标是理解容器逃逸检测的原理，这也是我第二个项目“第一个是容器全面检查和分析，感兴趣的人可以看看”

### 环境要求

- Debian 12 / Ubuntu 22.04（内核 5.x~6.1）
- Rust 1.70+
- Node.js 18+

> Debian 13 / 内核 6.12 不兼容 bpf-linker 0.10.4，eBPF 无法加载。

### 使用说明

**1. 编译后端**

```bash
cd ablock
cargo build --release
```

**2. 启动后端**

```bash
sudo ./target/release/ablock --foreground
```

**3. 启动前端**

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 `http://localhost:8080`

### 前端界面

| 功能 | 说明 |
|------|------|
| 容器列表 | 显示运行中容器 |
| 基线采集 | 5秒采样容器指标 |
| 监控开关 | 启动/停止监控 |
| 仪表盘 | 事件统计、阻断率 |
| 规则列表 | 查看检测规则 |
| 报告中心 | 历史报告下载 |

### API 接口

| 接口 | 功能 |
|------|------|
| `GET /api/containers` | 容器列表 |
| `GET /api/container/:id/limits` | 资源限制 |
| `POST /api/baseline/quick` | 快速基线 |
| `POST /api/start` | 启动监控 |
| `POST /api/stop` | 停止监控 |
| `GET /api/status` | 监控状态 |
| `GET /api/reports` | 报告列表 |
